# FRONTLINE: МЕРИДИАН

Браузерный тактический 3D-шутер на Three.js: большая процедурная карта, выбор оружия,
ФПВ-дроны, техника, бои с ботами, мультиплеер с лобби и система рангов.

Действие — вымышленный конфликт 2031 года в долине Меридиана. Стороны:
**VEGA** (западная коалиция, голубой) и **ARGO** (восточный альянс, янтарный).

---

## Быстрый старт

```bash
npm install
npm run serve     # сборка + сервер на http://localhost:8080
```

Для разработки с горячей перезагрузкой:

```bash
npm run dev       # vite на :5173, /ws проксируется на :8080
npm start         # в отдельном терминале — сервер лобби
```

Одиночный бой работает и без сервера: клиент сам становится хостом симуляции.

| Режим | Задача | Лимит | Время |
|---|---|---|---|
| **TDM** — Командный бой | Фраги | 60 | 15:00 |
| **DOM** — Доминирование | 3 контрольные точки, очко за каждые 3 с удержания | 250 | 15:00 |
| **PvE** — Зачистка | Отбить 15 волн | 15 волн | 20:00 |
| **PvP** — Дуэль | Фраги, только живые игроки, без ботов | 40 | 10:00 |

Карты: **Долина Меридиана** (460 м), **Хребет Крон** (400 м), **Квартал Северный** (330 м).
Рельеф, растительность, здания и объекты генерируются процедурно по сиду матча —
у всех игроков карта одинаковая.

## Состав

**Оружие** — 7 основных (`vixen`, `bulat`, `osa`, `sokol`, `groza`, `kuvalda`, `shershen`)
и 3 пистолета (`gyurza`, `revansh`, `vektr`); у каждого свои урон, темп, разброс,
отдача и поведение в прицеле.

**Гаджеты** (до 3 в вылазку): осколочная граната, дым, бронеплита, мина, развед-БПЛА.

**ФПВ-дроны** — `striker`, `hornet`, `swift`. Батарея, уровень сигнала и боевая часть;
ручное пилотирование от первого лица, пикирование на цель, детонация по нажатию.

**Техника** — `bulat_mb` (ОБТ), `kolchuga` (БТР), `rys` (БМП), `zmey` (багги).
Место водителя и пассажиров, башня с орудием и пулемётом, броня по бортам,
респаун через 45 с.

**Боты** — три уровня сложности: разница в реакции, точности, длине очереди,
агрессии и желании прятаться за укрытия. Боты воюют за обе стороны.

**Ранги** — 24 звания от Новобранца до Легенды Меридиана, 5 тиров
(бронза → сталь → золото → обсидиан → мифик). XP, статистика и настройки
хранятся в localStorage.

## Мультиплеер

Лобби: создание комнаты с кодом, подключение по коду, быстрый подбор, чат,
смена команды, готовность, настройки матча. До 16 игроков в лобби.

Архитектура **хост-клиент**:

- сервер Node.js держит комнаты, назначает хоста и ретранслирует пакеты;
- всю симуляцию (боты, счёт, точки, таймер, техника, респауны) считает хост;
- хост рассылает состояние 20 раз в секунду, клиенты шлют ввод с той же частотой;
- попадания валидируются на хосте (дистанция, живость цели);
- при выходе хоста его роль переходит следующему игроку.

Порты: `PORT` (по умолчанию 8080), `HOST` (0.0.0.0).

## Тесты

```bash
npm test          # оба набора
npm run test:game    # 39 тестов логики
npm run test:server  # 18 тестов протокола лобби
```

Тесты идут в Node без браузера: `tools/stub.mjs` подменяет DOM, WebGL-контекст,
`localStorage` и `WebSocket`, после чего настоящий `Game` прогоняется кадр за кадром
(физика, боты, урон, техника, дроны, все три карты, сценарии всех режимов).
Серверные тесты поднимают живой `server/index.js` и прогоняют протокол лобби:
коды комнат, команды, права хоста, чат, старт боя, ретрансляцию, миграцию хоста.

Что покрыто только частично: рендеринг WebGL, вёрстка, pointer lock и WebAudio —
для них нужен настоящий браузер.

## Структура

```
src/
  core/data.js       оружие, техника, дроны, карты, режимы, 24 ранга
  core/store.js      профиль, XP, статистика, настройки (localStorage)
  world/map.js       процедурная карта: рельеф, река, здания, коллайдеры, LOS
  entities/models.js солдаты, техника, дроны, вид оружия от первого лица
  game/actor.js      физика и бой актёра: урон, броня, разброс, респаун
  game/bot.js        ИИ: патруль, поиск, бой, укрытия, обход препятствий
  game/machines.js   техника и ФПВ-дроны
  game/effects.js    взрывы, дым, попадания, тряска
  game/game.js       цикл матча: режимы, счёт, захват точек, сеть
  net/client.js      WebSocket-клиент, автопереподключение, пинг
  ui/                интерфейс, HUD, экраны, стили
server/index.js      комнаты, коды, хосты, ретрансляция
tools/               тестовые наборы и заглушки окружения
```

## Стек

Three.js 0.169 · ws 8.18 · Vite 5. Без сборщиков ассетов и внешних моделек —
вся графика строится процедурно кодом.
